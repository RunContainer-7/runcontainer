First Stable release of RunContainer for Windows.

**Download:** `RunContainer-Setup-0.5.1.exe` (attached below). Check it against `SHA256SUMS.txt` before you run it.

## What's new

- **Update notice.** RunContainer checks for a newer Stable release when it starts, and then once a day while it is open. If one exists, a banner shows the version and a Download link. RunContainer never downloads or installs an update by itself: run the new installer over the old one, and your apps and environments stay.
- **Discord link is clickable** in the beta notice.
- **Links open in your browser**, not in a new RunContainer window.
- **Isolation wording updated.** Hyper-V VM is one of the isolation options in the app, not a fixed requirement. Messages that listed Windows editions and firmware settings as requirements were removed.

## Known limitations

- Windows only.
- The installer is not code-signed, so Windows SmartScreen may warn before it runs. Only run it if you downloaded it from this release.
- Users on 0.5.0 are not told about this release by the app, because 0.5.0 has no update check. Download it from the release page or the docs.
- Not every Windows application will work. Some installers expect system-wide installation or drivers.
- RunContainer isolates applications; it is not antivirus and does not guarantee safety.
